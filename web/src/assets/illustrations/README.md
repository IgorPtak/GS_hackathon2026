# Illustrations

These are hand-generated painted illustrations, made by the team with an image model.

- Each scene has a `-day` version for the light theme and a `-night` version for the dark theme.
- Each version comes as AVIF, with a WebP fallback.
- Every image is 2400 px wide and keeps its full composition. Crop in CSS with `object-fit: cover` and `object-position`, never in the file.
- No text is baked in; put copy over the calm area (usually the left side).
